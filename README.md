# Lab Code Vault: S1 & S2 Code Repository

A fast, interactive static web portal and repository containing complete Python numerical implementations for **Computational Methods** and **Differential Equations**.

## 📁 Repository Contents

| File | Description | Program Topics Included |
| :--- | :--- | :--- |
| **[`s1.txt`](./s1.txt)** | Program Bundle 1 | 1. Gauss-Seidel Method<br>2. Exact Differential Equation (SymPy)<br>3. Newton's Law of Cooling<br>4. Non-Homogeneous 2nd Order ODE |
| **[`s2.txt`](./s2.txt)** | Program Bundle 2 | 1. Gauss-Seidel Method<br>2. Non-Exact Differential Equation (Integrating Factor)<br>3. Newton's Law of Natural Growth<br>4. Homogeneous 3rd Order ODE |
| **[`index.html`](./index.html)** | Interactive Web Viewer | Dark-mode UI with instant 1-click clipboard copy, search filter, and modular program inspector |
| **[`style.css`](./style.css)** | Modern Design System | Sleek glassmorphism theme, glowing indicators, responsive layout |
| **[`script.js`](./script.js)** | Portal Interactivity | Clipboard API with fallback, program tabs, keyboard shortcuts |

---

## ⚡ Web Portal Features

- **Instant 1-Click Copy**: Prominent button to copy entire scripts (`s1.txt` or `s2.txt`) or individual problem snippets with visual feedback.
- **Search & Filter**: Real-time keyword filtering to locate specific ODE methods or numerical routines.
- **Dual View Modes**: Full continuous code view with line numbering, or segmented modular view by question.
- **Keyboard Shortcuts**:
  - `1`: Switch to **S1**
  - `2`: Switch to **S2**
  - `C`: Copy active file code
  - `/`: Focus search input

## 🚀 Live Demo / GitHub Pages

To view this portal live in your browser:
1. Go to your GitHub repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then click **Save**.
4. Your site will be published at: `https://<your-username>.github.io/projectcm/`
